# The L&D Detective Field Guide

Source of the one-page site at https://hannapetrasian.github.io/ld-detective/

A field guide for L&D partners: how to turn a training request into a business problem, run a 20-minute CLUE intake, and write an impact hypothesis a sponsor would sign.

Static HTML, no build step. `index.html` is the whole guide; `files/` holds the two downloads; `fonts/` the self-hosted Inter and IBM Plex Mono. `tools/` holds the Playwright verification harness (see `tools/README.md`); run it before every push. GitHub Pages serves the repo root from `main`.

Author: Hanna Petrasian
